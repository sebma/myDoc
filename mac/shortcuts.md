# macOS keyboard shortcuts
`~` : Option + n + Space

`|` : Option + Shift + l

`[` : Option + Shift + (

`]` : Option + Shift + )

`{` : Option + (

`}` : Option + )

Full-screen Screenshot : Cmd + Shift + 3

Region Screenshot : Cmd + Shift + 4

Screenshot Tool : Cmd + Shift + 5

See more at [Mac keyboard shortcuts - Apple Support](https://support.apple.com/en-us/102650)
