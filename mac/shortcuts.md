# macOS keyboard shortcuts
`` ` `` : `£` Key + Space

`~` : Option + `n` + Space

`|` : Option + Shift + `l`

`[` : Option + Shift + `(`

`]` : Option + Shift + `)`

`{` : Option + `(`

`}` : Option + `)`

`\` : Option + Shift + `/`

Lock the session : Ctrl + Command + `q`

Capture entire screen : Command + Shift + `3`

Region Screenshot : Command + Shift + `4`

Screenshot Tool : Command + Shift + `5` (See [Take a screenshot on Mac - Apple Support](https://support.apple.com/en-us/102646 )

Current Window Screenshot : Shift + Command + `4`, then `Space bar`

Hide Window : Command + `h`

Switch between windows of different apps : Command + Tab

Switch between windows of same app : Command + `` ` ``

Open Mission Control : Control + `Up Arrow`

Show all windows of the front app : Control + `Down Arrow`

Move to next virtual desktop : Control + `Right Arrow`

Move to previous virtual desktop : Control + `Left Arrow`

See more at [Mac keyboard shortcuts - Apple Support](https://support.apple.com/en-us/102650)
