# macOS keyboard shortcuts

`~` : Option + `n` + Space

`|` : Option + Shift + `l`

`[` : Option + Shift + `(`

`]` : Option + Shift + `)`

`{` : Option + `(`

`}` : Option + `)`

`\` : Option + Shift + `/`

Full-screen Screenshot : Command + Shift + `3`

Region Screenshot : Command + Shift + `4`

Screenshot Tool : Command + Shift + `5`

Hide Window : Command + `h`

Switch between windows of different apps : Command + Tab
